# Melting Layer Detection and Visualization using Micro Rain Radar (MRR) & Meteorological Data
This script contains a Python-based pipeline designed to identify, clean, and analyze the atmospheric melting layer using Micro Rain Radar (MRR) data and thermodynamics calculated from surface meteorological stations.

Using the approach established by Endries et al. (2018), the algorithm identifies the top of the melt layer as the most negative vertical gradient in radar reflectivity and the bottom of the melt layer as the most negative gradient in Doppler velocity. This allows for the continuous calculation of the melting layer's thickness throughout the storm. To ensure high-resolution accuracy, the real-world melt layer height is calculated minute-by-minute by taking the established bottom height and adding the average melt layer thickness for that respective hour. Rigorous quality control is then applied; derived heights are automatically discarded if they are: 1) outside one standard deviation of the hourly average, 2) above 6000 m altitude (considered implausible under current tropospheric conditions), or 3) occurring during virga, defined as instances where no precipitation is detected below 5500 m. Finally, these physical radar observations are validated against a thermodynamic baseline by dynamically calculating a theoretical freezing level based on surface temperatures and the moist adiabatic lapse rate.
